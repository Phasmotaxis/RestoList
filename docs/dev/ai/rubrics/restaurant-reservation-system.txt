5. **Database Integrity & Concurrency Guarantees (Doubt #4 Resolution):**
- **Half-Open UTC Intervals:** Reservations store `[start_at, end_at)` where `end_at =
start_at + turn_duration_minutes + buffer_minutes`. Two bookings overlap iff
`existing.start_at < new.end_at AND existing.end_at > new.start_at` for active statuses
(`pending`, `confirmed`, `seated`).
- **Two-Layer Double-Booking Lock:** Wrap every booking/modification in
`PDO::beginTransaction()`. Lock candidate `dining_tables` rows in deterministic `ORDER BY
id ASC FOR UPDATE` (MySQL) or `BEGIN IMMEDIATE` (SQLite), verify zero overlapping
active bookings, AND insert discretized 15-minute buckets into `reservation_slots (org_id,
table_id, slot_start_utc)` protected by `UNIQUE(org_id, table_id, slot_start_utc)`.
- **Combinable Tables:** Link bookings to tables via `reservation_tables (reservation_id,
table_id)` so parties larger than one table can atomically lock adjacent `is_combinable = 1`
tables in the same `dining_zone`.
- **Safe Mutations:** All foreign keys enforce `ON DELETE RESTRICT`. Tables, zones,
and menu items use soft-archiving (`archived_at DATETIME NULL`). Block archiving a table
or reducing its `capacity` if any future active reservation (`end_at > NOW()`) references it.

- **Centavos & Append-Only Ledgers:** Store all currency amounts as signed integer
centavos (`BIGINT`). Record deposit holds/forfeits/refunds in immutable `deposit_ledger`
rows and optional inventory changes in immutable `stock_movements` rows.

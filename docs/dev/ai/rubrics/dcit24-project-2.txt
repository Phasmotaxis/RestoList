Project Descriptions

I. PROJECT OVERVIEW:
•
For this final project, students are required to design, develop, and demonstrate a fully functional, database-driven web
application using HTML, CSS, PHP, and MySQL.
•
Students shall develop a web-based information system that addresses a specific problem, improves an existing manual
process, or provides a practical solution to a real-world situation.
•
The developed system must allow users to interact with a website while performing database operations such as inserting,
retrieving, updating, and deleting records.

Database Requirements
✓ The database must contain at least four (4) interconnected tables relevant to the proposed system.
✓ Each table must have a clearly defined Primary Key (PK).
✓ Foreign Keys (FK) must be implemented where necessary to establish relationships between tables.
✓ Appropriate SQL data types must be used, such as INT, VARCHAR, TEXT, DATE, DATETIME, and DECIMAL.
✓ The database must contain sufficient sample records to demonstrate the system's functionality.
✓ Database records must be stored and retrieved from MySQL rather than hardcoded into the website.
✓ Students must demonstrate the use of SQL statements, including SELECT, INSERT, UPDATE, and DELETE.

V. IMPORTANT REMINDERS
•
Originality of Work. Students must develop their own project. Copying an existing system, downloading a complete project
from the internet, or submitting another group's work as their own is strictly prohibited.
•
Use of Artificial Intelligence. AI tools may be used as learning aids for understanding programming concepts, debugging, or
obtaining explanations. However, students must understand, verify, and be able to explain any AI-assisted code included in their
project. Submitting a fully AI-generated system without understanding its implementation is not acceptable.

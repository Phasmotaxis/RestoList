\begin{abstract}
This monograph presents the formal specification, engineering methodology, and architectural verification of the Enterprise Information Management System (EIMS). Developed for Cavite State University (CvSU) under DICT24 Information Management, EIMS achieves complete multi-tenant administrative isolation without external framework overhead. The system implements clean-room native PHP 8.3, a mathematical bitmask Role-Based Access Control (RBAC) model, dual-driver relational persistence abstracting primary MySQL 8.0 and offline SQLite3 failover, and a live panel sabotage defense kernel. Empirical verification confirms sub-millisecond route resolution across 13 canonical system endpoints and continuous fault interception.
\end{abstract}
